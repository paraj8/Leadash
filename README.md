# Leadash CRM

Leadash CRM is a modern full-stack MERN recruitment and lead management platform built with React, Node.js, Express, and MongoDB.

The platform includes multi-role authentication, dashboard systems, task management, lead assignment workflows, and modern SaaS-style UI architecture.

---

# 🚀 Features

## 🔐 Authentication System
- JWT Authentication
- Login & Registration
- Protected Routes
- Role-Based Access Control

---

# 👥 Multi-Role System

## 👑 Admin
- Manage recruiters
- Manage candidates
- Create and assign leads/tasks
- View analytics and system stats

## 🧑‍💼 Recruiter
- View assigned leads
- Assign tasks to candidates
- Manage candidate workflow

## 👤 Candidate
- View assigned tasks
- Update task status
- View recruiters and team members

# ⚡ Installation

## Clone Repository

```bash
git clone https://github.com/your-username/leadash.git
```

---

## Backend Setup

```bash
cd server
npm install
npm run dev
```

---

## Frontend Setup

```bash
cd client
npm install
npm run dev
```

---

# 🔑 Environment Variables

Create `.env` file inside `server`

```env
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
```
